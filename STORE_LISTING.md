# Chrome Web Store Listing

## Name

ResultBoard

## Summary

Turn Google results into a calm, organized research board with local projects, notes, tags, and comparison tools.

## Detailed description

Research without losing your place.

ResultBoard adds clear Keep, Maybe, and Reject controls to organic Google Search results. Saved results appear immediately in a focused side panel and a responsive full-page board.

Organize work with unlimited local projects, notes, rejection reasons, tags, filters, sorting, and archives. Select up to four results and rate them against your own weighted criteria. Export an active project to CSV, JSON, Markdown, or standalone HTML, or download a complete JSON backup for safe merge/replace import.

ResultBoard is local-first. This release has no account, subscription, advertising, analytics, telemetry, crash reporting, or cloud sync. Saved result data and the associated search-query context remain in Chrome local extension storage unless you explicitly export a file.
